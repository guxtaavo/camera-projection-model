# 📷 camera-projection-model
 
> Assignment 1 — Computer Vision (2026/1) | UFES
 
A Python application for visualizing and interacting with the **Rigid Body Motion and Perspective Projection Model**. It allows real-time manipulation of camera extrinsic and intrinsic parameters, with synchronized 3D scene visualization and camera image output.
 
---
 
## 🚀 Features
 
- 3D visualization of camera position and orientation relative to an object
- Interactive control of **extrinsic parameters** (position and orientation via translations and rotations)
- Support for transformations in both the **world frame** and the **camera's own reference frame**
- Real-time rendering of the **image generated by the camera**
- Control of **intrinsic parameters** (focal length and scale factor per axis)
- Automatic update of the **principal point** when image or sensor size changes
- Every parameter change updates both the 3D view and the camera image instantly

## 📐 Notes
 
- The object remains static; only the **camera is moved**
- The origin of the image axes is at the **top-left corner**
- The principal point is updated automatically when image or sensor dimensions change
